# Кольцо — лендинг

Статический лендинг сервиса мониторинга инфраструктуры. Чистый HTML/CSS/JS, без сборки.

Собран по скиллу `landing-page-design` (github.com/elayadesign/ai-design-skills).

## Локально

Откройте `index.html` в браузере.

## Форма

В `script.js` есть `var ENDPOINT = "";` — пока пусто, форма работает в демо-режиме. Подставьте URL бэкенда, чтобы включить реальную отправку.
